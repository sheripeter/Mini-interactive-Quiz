# JavaScript Mini Quiz

My first interactive JavaScript project, built while learning frontend development.

## Features
- Multiple-choice answers
- Correct and incorrect answer feedback
- Score tracking
- Prevents repeated scoring
- Disables answer buttons after a correct answer
- Reset button to play again

## Technologies
- HTML
- CSS
- JavaScript

## What I learned
- JavaScript variables and functions
- Conditions and Boolean values
- DOM selection with `querySelector()`
- Click events with `addEventListener()`
- Updating webpage content with `textContent`
- Enabling and disabling buttons

## How to run
Open `index.html` in a web browser.
